An optimizer for problems with a known computation graph.

Free. Fully local — no server, no license key, no network call, the same as torch.optim.Adam. If you can write down your objective exactly, SoftOpt uses it to correct your optimizer's trajectory on every step.

Where it helps

Any problem with a known, differentiable computation graph — a quantum circuit, a physical simulator, a projection model — even when what you actually measure is noisy.

Where it doesn't help

Two honest limits, stated plainly rather than discovered the hard way:

  • A moving target. Full reinforcement learning — or anything with a continuously shifting policy, adversary, or distribution — is outside SoftOpt's validated scope. The correction needs a fixed objective to compute against.
  • A landscape with unpredictable curvature. Some problems don't have consistently one-signed curvature. SoftOpt's default newton mode assumes they do; mode="mobius" is built for when it doesn't hold.

Quick start

# numpy
from softopt import SoftOpt

opt = SoftOpt(n_params, g_delta, lr=0.02)
for step in range(num_steps):
    grad_estimate = my_gradient_estimate(theta)
    theta = opt.step(theta, grad_estimate)

# PyTorch
from softopt import SoftOptTorch

opt = SoftOptTorch(model.parameters(), model, loss_fn, lr=1e-3)
for batch in data:
    loss = opt.step(batch)

g_delta(theta, delta) must be the exact directional derivative of your true objective, computed from your own known model — not estimated from noisy measurements. If you can't write it without sampling the world, SoftOpt isn't the right tool for that problem.
